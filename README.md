# Low-Latency-Neural-Network
Low latency neural network with feed forward and back propagation algorithms

The repository acts mainly to store multiple iterations of feed forward and back propagation algorithms, which are integral to the functioning of a multi layer percepteron network. Both files include main functions to test the latency of the algorithm implementations. The back propagation algorithm is coded in C++ using SIMD and the feed forward algorithms are coded in ARM64 also using SIMD.
